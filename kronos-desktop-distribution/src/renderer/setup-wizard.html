What is KRONOS?

KRONOS is a comprehensive AI-powered desktop automation platform that combines multiple AI services into a unified interface. It can handle web automation, computer vision, text analysis, and system control through intelligent AI agents.

Key Features

  • ✓ Embedded AI services for computer vision and automation
  • ✓ Web automation using Puppeteer
  • ✓ Text analysis and OCR capabilities
  • ✓ Cross-platform compatibility (Windows, macOS, Linux)
  • ✓ Real-time WebSocket communication

System Requirements

  • • 4GB RAM minimum (8GB recommended)
  • • 2GB disk space available
  • • Active internet connection for AI services
  • • Windows 10+, macOS 10.15+, or Linux
